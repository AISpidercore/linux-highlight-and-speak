# Usage Instructions for linux-highlight-and-speak

## Overview  
`linux-highlight-and-speak` is a tool that allows users to highlight text and have it read aloud. This document provides detailed instructions on how to use the application effectively.

## Selecting Text  
To select text for reading, follow these steps:
1. Open the application or any text editor that supports text highlighting.
2. Use your mouse to click and drag over the text you wish to highlight.  
   - Alternatively, you can hold down the `Shift` key and use the arrow keys to select text.

## Click the Read Aloud Button  
Once you have selected the text:
1. Look for the `Read Aloud` button within the application interface.  
2. Click the button to begin playback of the highlighted text.

## Stop Playback  
To stop the playback:
- Click the `Stop` button located next to the `Read Aloud` button or use the keyboard shortcut to halt playback.

## Keyboard Shortcuts  
The following keyboard shortcuts can enhance your experience:
- **Read Aloud:** Press `Ctrl + R` after selecting text to start playback.
- **Stop Playback:** Press `Ctrl + S` to immediately stop any ongoing audio output.
- **Pause/Resume Playback:** Press `Ctrl + P` to pause and resume the playback of the text.

## Practical Examples  
### Example 1: Reading Aloud a Paragraph  
1. Select the paragraph you want to read.
2. Click the `Read Aloud` button or press `Ctrl + R`.
3. To stop at any time, click `Stop` or press `Ctrl + S`.

### Example 2: Reading a List  
1. Highlight the list items.
2. Use the `Read Aloud` feature as described above.  
3. The application will read each item in sequence.

### Example 3: Using Keyboard Shortcuts  
1. Select your desired text.
2. Instead of clicking the button, press `Ctrl + R` to start reading aloud.  
3. You can press `Ctrl + S` to stop or `Ctrl + P` to pause and resume as needed.

## Conclusion  
The `linux-highlight-and-speak` application offers a user-friendly interface for reading aloud text. By following these instructions, you can efficiently utilize the application's features for an enhanced reading experience.

Happy listening!
